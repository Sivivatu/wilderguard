## Reviews

Planner/TDD guidance, general review and native security review were collected. Fixed findings: fail-closed destination cache purge; notice moved out of game initialization and ahead of reporting; acknowledgment stored only on dismissal; filter only unhandled exceptions; reuse the browser offline transport across toggles. Capacitor's native calls are serialized on its plugin handler thread; the reviewer retracted an initial native init/close concurrency concern after inspecting that implementation. Final reviews found additional issues with rapid toggles, re-enable after a failed opt-out purge, and the browser SDK marking manual startup captures handled. Corrections use generation-bound startup attempts, await prior shutdown, purge successfully before persisting on, and normalize the private startup mechanism in beforeSend. Regression tests cover each; the actual SDK startup fixture delivered a sanitized error. No further agent review of those small corrections was requested; they were verified locally.
